# Fold 36 apps into three products

**Most of the portfolio should be deleted or archived, not migrated.** Of roughly 36 apps and repos, about seven pieces carry real value into the three products. Rennstern absorbs Rennstream's R2 storage and Mac-app API, Film Agent Pro's Werbepass and Stripe flow, and Skill Spark's ten skill files. VibeCoin Events gets a "Studio" built from Tekk Rack, VoxLive and the RaveSwitch auto-VJ. Only Trend Weaver Studio clearly justifies its own GitHub repo, Cloudflare Worker and secrets today, and it needs no Supabase at all. The live Vintage Closet shop is already standalone and stays where it is. The first job is not a merge but a storage fix. Rennstern's own transfer feature ("Streamseeds") advertises 5 GB files on Supabase Storage, and a planned move to Supabase Free caps uploads at 50 MB, so porting Rennstream's R2 object store comes before anything else. On cost, the consolidated setup runs on **about $5/month** (Cloudflare Workers Paid plus Supabase Free, with R2 inside its free 10 GB) or **about $30/month** with one Supabase Pro project. That compares with $45/month or more for keeping Lovable Pro and Replit Core. The cheap route only works if apps share Supabase projects carefully. It also depends on clearing four risks: data that exists only in Lovable Cloud or Replit Postgres, secrets committed or stored in .env files, a database table that anyone on the internet can read and delete, and old transfer links.

## Rennstern is already half-merged with Rennstream; storage is the blocker

Rennstern already runs its own file transfer. The `/transfer` page is branded "Rennstream" and backed by Streamseeds, which advertises up to 12 GB per transfer and 5 GB per file ([Source](file:///home/user/rennstern/src/routes/transfer.tsx)). It also already includes the MysteryCourier UI copied from Rennstream ([Source](file:///home/user/rennstern/src/components/transfer/)). Merging Rennstream therefore does not mean bringing in a second transfer engine. It means moving the parts Rennstern still lacks. The most important is **R2 storage**. Streamseeds writes to a Supabase Storage bucket and has no R2 path at all ([Source](file:///home/user/rennstern/src/lib/streamseeds.server.ts)). On Supabase Free the maximum upload is **50 MB per file** and the storage limit is **1 GB** ([Source](https://supabase.com/pricing)). The planned move to Free would quietly break the advertised 5 GB transfers. Rennstream's `object-store.server.ts`, which signs R2 requests with aws4fetch, is the fix. The migration plan says its R2 branch is "done, tested against an S3 stand-in, not pushed" ([Source](file:///home/user/rennstern/docs/MIGRATION.md)).

Three smaller steps follow. First, rebuild `api/app/transfers` on top of Streamseeds, so the Mac app and the admin `RennstreamLivePanel` call Rennstern directly. The remote fetch and the `rennstream_app_key` studio secret can then be removed ([Source](file:///home/user/rennstern/src/lib/rennstream-admin.functions.ts)). Second, replace the 301 redirect in `rennstream.$.tsx` with a hostname check inside the Worker, so `rennstream.rennstern.com` and old `/t/CODE` links keep working ([Source](file:///home/user/rennstern/src/routes/rennstream.$.tsx)). Third, port user accounts, premium, roles and abuse reports only if public sign-ups are wanted. Rennstream defines `profiles`, `user_roles`, `payments`, `set_updated_at` and a `handle_new_user` trigger on `auth.users`, and these names collide with Rennstern's own ([Source](https://lovable.dev/projects/7995e594-9258-443e-9a5c-dbe51868cc85)). If they are ported, give them a prefix such as `rs_`. Only Rennstream's users need to move, because its transfers expire within days ([Source](file:///home/user/rennstern/docs/MIGRATION.md)).

Three other apps fold into Rennstern for almost no work. Film Hub's `companies` table is a subset of Rennstern's `pipeline_companies`, and Rennstern already finds leads with real Perplexity research and writes outreach drafts ([Source](file:///home/user/rennstern/src/lib/pipeline.functions.ts)). Fresh Sync Push's enquiry → status → inbox flow duplicates Rennstern's `booking_requests`, `booking_status_events` and `notifications` ([Source](file:///home/user/rennstern/src/lib/outbound-mail.server.ts)). Skill Spark is an empty placeholder app holding ten brand-voice and service skill files ([Source](https://lovable.dev/projects/84f1dee6-db5f-45d2-9862-bb8d8336bc96)). Film Agent Pro is the bigger Replit asset. It overlaps Rennstern in booking, chat, admin, portfolio and equipment pricing, and it adds Stripe subscription tiers. Rennstern already has a `werbepass-check` endpoint, so the merge is mostly the Stripe and tier logic plus the streaming booking chat ([Source](file:///home/user/team/research_notes/App%20portfolio%20integration%20options/replit_apps.md)). The notes give no effort estimate for this port, and it is the least-scoped item in the plan.

## VibeCoin gains a Studio; Rennstream gains nothing from anyone

VibeCoin Events (repo SobhiAksh/vib-finder, branch `claude/sweet-brown-asyghx`, PR #1, deployed to the `vibecoin` Worker at vibecoin.rennstern.com) shares the same TanStack Start, Tailwind v4 and shadcn base as the music apps. It also has a multi-provider AI gateway (Lovable, Gemini, Claude, OpenAI) ([Source](file:///home/user/vib-finder/src/lib/ai-gateway.server.ts)). That makes it the natural home for a "Studio" area for hosts and artists. **Tekk Rack** (S) moves first. It runs in the browser apart from one AI call, and that call already falls back to a local generator when the Lovable gateway is missing ([Source](https://lovable.dev/projects/07717610-0059-45d5-bb3b-892baac1903c)). **VoxLive** (S–M) has no backend, and its `autotune-processor.js` must stay a static asset loaded through `audioWorklet.addModule`. **RaveSwitch VJ** goes in two phases. Phase 1 (M) is phone-camera auto-VJ plus recording to 1080p clips for event aftermovies. It uses VibeCoin's existing Supabase Realtime for camera signalling. It also needs a TURN relay server, because the current setup uses Google's STUN server only, and phone cameras behind venue Wi-Fi or mobile data will often fail to connect ([Source](https://lovable.dev/projects/20684a92-2326-4db4-a18b-a6700dccb24f)). Phase 2 (L) replaces the RTMP stub with WHIP output to a managed live-streaming service, because ffmpeg cannot run inside a Worker. Tekk Rack's engine should become the single shared synth, and VJ's duplicate `aiSynth.ts` can then be deleted.

The other VibeCoin-related leftovers are archives with one exception. vienna-pulse's routes and its 3 migrations all exist in vib-finder already. The older VibFinder repo, however, holds an **Admin Smart Panel** (about 300 lines of radar filter presets stored in localStorage) that is missing from vib-finder's legacy backup. Port it or write it down before archiving ([Source](file:///home/user/vibfinder/client/src/components/AdminSmartPanel.tsx)). Two tie-ins are possible but should wait. The Memory Loop's Vienna night-train story fits an "After Dark" easter egg, but any coin reward would need a check on the server, because saves live in the browser and can be faked ([Source](https://lovable.dev/projects/791574fd-3f6b-435a-9679-1c8d9f4356a3)). Sahha's "Rave Recovery" party packs could become `store_items` rows once VibeCoin has payments, which its README says are not enabled yet ([Source](file:///home/user/vib-finder/README.md)).

Nothing in the portfolio should merge *into* Rennstream. No Replit app overlaps it, and the owner's stated goal is "Rennstern + Rennstream = ONE project, ONE database" ([Source](file:///home/user/rennstern/docs/MIGRATION.md)). After this plan, Rennstream survives only as a brand and a subdomain on the Rennstern Worker.

## The order: back up first, fix storage second, add features last

**Step 1 is a backup freeze, and it is the only step that cannot be undone if skipped.** Five Lovable projects exist only on Lovable: Rising Path, Sahha, Sentinel Watch, Private Preview Launchpad and Fresh Sync Push. Only Gentle Day Tracker has a current GitHub copy ([Source](https://lovable.dev/projects/f20ae311-a8b6-43d3-8dfc-067cff7c01ae)). Lovable-linked repos stay on GitHub after a project is disconnected or deleted. Lovable Cloud data, however, must be exported and restored by hand, and "Remove database" deletes users and files permanently ([Source](https://docs.lovable.dev/integrations/cloud)). A deleted Lovable project can be restored for 60 days ([Source](https://docs.lovable.dev/features/projects/delete-project)). Replit's zip and Git exports leave out secrets, the database and deployment settings ([Source](https://docs.replit.com/help/projects-and-files)). Film Agent Pro, Sonic Scribe and Future Oasis therefore each need a `pg_dump` of their database before their subscription lapses. Nobody has yet queried row counts in any of these databases, so before deleting anything, check Rennstream's users and Film Hub, Sahha, Sentinel and Fresh Sync Push for real rows. In the same step, turn off Film Hub's backend. Every one of its tables has a "public full access" policy, and anonymous users can delete files in its public bucket ([Source](https://lovable.dev/projects/1a24f44a-338a-4084-9036-29da14f6f743)).

Step 2 deletes the empty apps, which carries no risk. Step 3 finishes VibeCoin PR #1, which is already in progress. Step 4 is the Rennstern storage work: R2 into Streamseeds, then the app API, then host routing, then copying Rennstream's users. After that the separate Rennstream Supabase project can be deleted, freeing a Free-plan slot. Step 5 copies Skill Spark's files into Rennstern and ports the Film Agent Pro tiers and Stripe flow. Step 6 builds the VibeCoin Studio in the order Tekk Rack, VoxLive, VJ phase 1, with VJ phase 2 only if hosts actually want live streaming. Nothing in the code shows that they do ([Source](file:///home/user/vib-finder/docs/VIBECOIN_EDITION.md)). Step 7 moves Trend Weaver to its own repo and Worker. It swaps the Lovable AI gateway, which uses model ids that only Lovable recognises, for the Rennstern AI-gateway pattern, and its YouTube OAuth credentials and `PUBLISH_PASSCODE` move into Worker secrets ([Source](https://lovable.dev/projects/47a02e4b-aba0-4232-bc59-beb459fe1ce7)). Its video rendering must stay in the browser, because Workers have no ffmpeg. Step 8 archives the backed-up repos and cancels Lovable and Replit. Published Lovable apps stay live after a downgrade ([Source](https://docs.lovable.dev/features/publish)).

## Five dollars a month buys the hosting; Supabase sharing is where the risk sits

Cloudflare charges per account, not per Worker. The Paid plan costs **$5/month** for up to 500 Workers, 10 M requests and 30 M CPU-ms. Requests for static assets are free, and data transfer costs nothing ([Source](https://developers.cloudflare.com/workers/platform/pricing/)). One Worker per app costs the same as one Worker in total, and gives each app its own deploys, rollbacks and secrets. Free is a false economy for apps that render pages on the server. Free allows **10 ms CPU** per request, while Cloudflare says server-side rendering typically uses 10–20 ms. Free also allows only 5 cron triggers per account ([Source](https://developers.cloudflare.com/workers/platform/limits/)). One zone such as rennstern.com can host 100 custom domains, so app subdomains add no cost. R2 gives **10 GB free**, then $0.015 per GB-month, with free egress ([Source](https://developers.cloudflare.com/workers/platform/pricing/)). Because transfers expire after 7 days, Rennstream-style traffic fits that free allowance unless several 12 GB transfers sit in storage at the same time.

Supabase is the real constraint. Free allows only **2 active projects**, pauses a project after a week without activity, and includes no backups ([Source](https://supabase.com/pricing)). VibeCoin's docs say both slots are already taken by Rennstern and Rennstream ([Source](file:///home/user/vib-finder/docs/VIBECOIN_EDITION.md)). The notes do not show where VibeCoin's own database runs, and that needs checking. Merging Rennstream frees one slot for VibeCoin. On Pro, the first project costs $25/month and each additional project at least $10/month, so ten separate projects would cost about $115/month against $25 for one shared project ([Source](https://supabase.com/pricing)). The plan above needs only two databases, Rennstern and VibeCoin. Trend Weaver and the parked browser-only apps need none. That fits Free if a paused project is acceptable, and costs $35/month on Pro with two projects. Supabase supports sharing one project through separate schemas ([Source](https://supabase.com/docs/guides/api/using-custom-schemas)). The cost of sharing is a single `auth.users` table, a single Site URL and set of email templates ([Source](https://supabase.com/docs/guides/auth/redirect-urls)), a single service-role key that can read every app's data, and restores that cover the whole database at once. Those are inferences from how Supabase works, not documented warnings. For the paying product, Rennstern, the case for its own project is strong.

Secrets need a specific clean-up list. RaveSwitch VJ has a `.env` file committed to its code, and it must be removed from git history before the code reaches VibeCoin ([Source](https://lovable.dev/projects/20684a92-2326-4db4-a18b-a6700dccb24f)). Sahha, Sentinel, Private Preview Launchpad and Fresh Sync Push each contain a `.env` that must not be committed when exported. Private Preview Launchpad also hard-codes the owner's birth date and birthplace in a signup trigger, so it may only ever live in a private repo ([Source](https://lovable.dev/projects/9fe2210b-e902-405c-a708-49c9f681684c)). Every `LOVABLE_API_KEY` dependency, in Tekk Rack, Trend Weaver and Film Hub's mail, has to move to direct provider keys. Rennstern's own rules apply throughout: never force-push, because pushing `main` syncs to Lovable ([Source](file:///home/user/rennstern/docs/MIGRATION.md)).

## Conclusion

The portfolio is less a set of products than a record of experiments: most Lovable side projects were built in a single sitting and never touched again ([Source](https://lovable.dev/projects/4b46d1b2-9b61-4e21-bc7c-b7897bca85e1)). The useful move is to stop treating "migrate" as the default verdict. Moving each app to its own repo, Worker and Supabase project is cheap on Cloudflare and expensive on Supabase. So the database-backed side projects (Sahha, Sentinel, Future Oasis) should become archives, not live apps, until one earns a business case. The browser-only toys can be revived on a static Worker at no extra cost whenever wanted.

The decisive dependency is not a product decision but an infrastructure one. Until R2 replaces Supabase Storage under Streamseeds, Rennstern cannot drop to Supabase Free without breaking its headline transfer promise. Until Rennstream's database is merged and deleted, VibeCoin has no free Supabase slot of its own. Fixing storage first unblocks both, and every merge and new feature after that is optional.
